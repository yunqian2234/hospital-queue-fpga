## 1. 改了什么

| # | 改动 | 现在的效果 |
|---|---|---|
| 1 | 音频柱形图 | 16 根跳动柱子（青绿柱身 + 琥珀色峰值帽），在原波形框的右半边（x 320~575，y 252~315，高度、上下位置不变）。柱子表示音量起伏，最新的在最右边，每秒约 12 次向左滚动；峰值帽跟着柱子跳上去，再慢慢落下 |
| 2 | SW2 开关柱形图 | **SW2 拨上**：播放音乐或语音时显示柱形图；**拨下**：隐藏。SW2 = C7，原来没用 |
| 3 | 两行叫号 | 第一行“请 **006** 号”，第二行“到 **02** 诊室就诊”。数字是原来的 96 像素琥珀色大字，其余是 30 号粗体深色字，和数字底边对齐。没叫号时第一行显示“等待叫号”，第二行空着。“请留意屏幕”胶囊放在第一行“号”字右边 |
| 4 | SW1 音量行常驻 | **SW1 拨上**：底行一直显示“亮度 / 对比度 / 音乐 / 语音 / 轮播”，当前正在调的那一项（音乐或语音，KEY3 切换）下面有琥珀色下划线。**SW1 拨下**：常驻温馨提示；调亮度、对比度后照旧显示 3 秒 |
| 5 | 字幕颜色 | 滚动字幕改为橙红色 #C2410C（“温馨提示”四个字仍是青绿色） |

底行优先级（高到低）：红色操作提示（3 秒）> 音量行（SW1 拨上，或拨下时调节后 3 秒）> 原图分辨率（SW4）> 温馨提示字幕。
