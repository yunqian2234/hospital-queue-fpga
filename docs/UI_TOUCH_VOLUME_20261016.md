## 按键与拨码

2026-10-17修正：音量模式使用开发板丝印 **KEY2、KEY3、KEY4**。此前接管外接八键，导致拨码显示变化但板载按键未切换。板载KEY1/Config/A2仍是复位。

SW1/C8上拨进入调音，下拨恢复原媒体操作；SW3/C6选择亮度/对比度，SW4/C5缩略图保持原状。无需改接杜邦线。

| 板载按键 | SW1下拨：原功能 | SW1上拨：调音 |
|---|---|---|
| KEY4 / C1（RTL端口key2） | 短按切换自动轮播；长按松开回上一张 | 当前音量减10个百分点 |
| KEY3 / B1（RTL端口key3） | 调亮度；SW3上拨时调对比度 | 切换音乐 / 叫号与辅助表达 |
| KEY2 / B2（RTL端口key1） | 下一张照片 / 缩略图焦点 | 当前音量加10个百分点 |
| KEY1 / Config / A2 | 复位 | 复位 |

J1外接K1～K8在两个模式下始终保留叫下一位、直接重播、应答求助、上一卡、下一卡、预览/确认、患者重播/返回、取号。触摸屏、诊室命令与语音完成也继续工作。

调音范围0～100%，不回绕；KEY4+KEY2同拍不加减。按住只执行一次；切换模式时已按住的键必须先松开再按。板载三键共用一份hospital_key_frontend的20ms消抖，原媒体内部消抖在正式顶层编译裁剪；启动/复位按住不产生动作。KEY4的短/长按在正常模式仍于松开判定，切换模式明确取消未完成的手势，避免误切图或自动轮播。

上电/复位默认音乐20%，播报100%。播报100%是保留之前的125%饱和增强基准；音乐100%是原PCM基准。10%为标称档位，硬件Q8近似增益（例如音乐20%=51/256）。两个音量独立，开关拨回后数值保留，复位后恢复默认；不写Flash。降到0为静音，HDMI/I2S时钟与业务仍运行。增益在约5.33ms内平滑变化，避免突然跳档。

调音模式只接管板载KEY4/KEY3/KEY2；外接八键、触摸提交、诊室命令、语音完成与心跳一直有效。大厅底栏在调音时显示两路百分比及当前选中项；拨回后恢复原亮度/对比度/自动/图片/错误底栏。
