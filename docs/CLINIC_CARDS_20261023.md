# 诊室板表达卡片：TF 卡读图 + 放大动画 · 2026-10-23

本次只改了**诊室板**。大厅板源码、约束、工程文件全部没动，大厅 bit 不需要重新编译。助手生成的 bit 只用于核对，**不作交付**；请队员在 TD 界面编译诊室工程，再下载到诊室板。

## 效果

- 诊室屏下半部分新增两排、每排三张的表达卡片（120×90），顺序与触摸屏一致：请帮助我、请写下来、请再说一遍 / 是、不是、不是这个意思。KEY2/3/4 的操作说明移到卡片右侧。原有的当前号码、求助状态、患者表达、下一位/候诊/已取号、操作结果都保留，整体往上挪，字号不变。
- 患者在大厅触摸屏点一张卡后：诊室屏上对应的小卡片约 0.3 秒内从原位置**移动并放大**到屏幕中央（360×270，先快后慢），周围画面变暗；**停 5 秒后自动缩回**原位。"请帮助我"用红框，其他卡片用蓝框。放大时用双线性插值，边缘平滑。
- 放大期间再点**同一张卡**：忽略。放大期间点**另一张卡**：当前卡片提前缩回，接着放大新卡。
- 患者求助（"请帮助我"、求助待处理）时同样会放大"请帮助我"，蜂鸣器和求助框照旧。
- 上电或网线重连后的头两帧只记录状态，不会因为旧的"最近一张卡"而误放大。
- 底部的蓝框始终标出患者最近选的那张卡。

**大厅板不改带来的一个限制**：卡片缩回后，患者**再点同一张卡**不会再放大一次，因为大厅发来的"最近一张卡"没有变化。点别的卡、或者先点别的卡再点回来都正常。如果要支持，需要在大厅状态帧里加一个点击计数，大概改十几行。但大厅改动后要重新扫种子并补做 fix_hold，所以这次没做，需要的话再说。

## TF 卡（诊室板）

- 用一张单独的 FAT32 卡插到**诊室板**的 TF 卡槽。根目录放 `CARD1.BMP`～`CARD6.BMP`。不需要 PIC/AUDIO/VOICE 这些文件；就算有也不影响。
- 格式：**120×90、256 色（8 位）BMP、不压缩**。用 Windows 画图打开后"另存为 → 256 色位图"即可，GIMP 导出的 V5 文件头也能读。
- 调试用的 6 张示意图：`delivery/clinic_cards_20261023/tf_card_clinic/`，`_all_previews.png` 是总览。
- **不插卡、某张卡读不出、或尺寸/格式不对**：这张卡在格子里显示文字（如"请写下来"），放大时先是白框，到位后在白框中间显示大号文字，其他功能都不受影响。上电后再插卡也可以，大约 2 秒内会自动重新读卡。
- 读卡用诊室板自己的 25 MHz 视频时钟，SPI 先 390 kHz 初始化，之后 6.25 MHz。6 张卡总共约 60 KB，上电后不到 1 秒就能读完。
