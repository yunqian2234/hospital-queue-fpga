# “请留意屏幕”提示：只保留胶囊，重播也提示  2026-10-26（晚）

工作目录：`20261021/lab_ex5_i2s`。只改了源文件、工程、测试和文档；不交付 bit 文件，不写 Flash。

## 1. 改了什么

| 情况 | 现在大厅屏的效果 |
|---|---|
| 叫到登记了“听力差”的患者 | 号码右边出现琥珀色胶囊“请留意屏幕”，每 16 帧亮灭一次，持续 5 秒 |
| **重播**（诊室按“重播”，或触摸屏点“重播叫号”，被大厅接受时） | 同样的胶囊闪烁 5 秒；5 秒内再次重播，就从头再计 5 秒 |

- 删掉了毛玻璃底板和左侧琥珀色细条，叫号区其余部分和平时完全一样。
- 大号码一直是琥珀色。
- 被拒绝的重播不会触发胶囊，例如还没叫号、同一个号已经在排队重播。

效果图：`delivery/pill_replay_20261026/pill_preview.png`。上排是叫到听力差患者，下排是重播；左边胶囊亮，右边胶囊灭。
