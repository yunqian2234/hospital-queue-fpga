# 10/29 音频频谱柱（扩展要求 5）

## 为什么改

赛题扩展要求 5 原文是："通过 FFT 或自研 DFT 模块计算频谱能量，将频谱柱状图或波形渲染为 RGB 像素数据，与视频帧在 HDMI 输出前叠加"。10/28 做的柱子显示的是**音量随时间的起伏**，算不上频谱，也没有 DFT，上板效果也不理想。这次改成真正的**频谱柱**。

## 看到的效果

- 位置、颜色、SW2（C7）开关都和 10/28 一样：16 根青绿柱子，顶上有琥珀色峰值帽，在原波形框的右半边，x 320..575，y 252..315。
- **左边是低音，右边是高音**：各柱中心频率按对数间隔排开，60 Hz、85、122、173、247、351、500、711 Hz、1.0 kHz、1.4、2.1、2.9、4.2、5.9、8.4、12 kHz。
- 柱高单位是分贝：1 像素 = 0.5 dB，满高 61 像素约 30 dB。
- 某个频段变弱时，柱子每帧落 2 像素；峰值帽每 3 帧落 1 像素。
- 音乐里高频能量本来就小，所以最右 4 根柱子分别抬高 2、4、6、8 dB，免得一直贴底。
- 预览图在 `delivery/spectrum_20261029/preview/`：
  - `sweep_stills.png`：单音从 40 Hz 扫到 16 kHz，亮的柱子从左走到右。
  - `song_stills.png` 和 `song.gif`：板上那首音乐。

## 怎么算的（答辩可以这样讲）

1. **自研 DFT（Goertzel 算法）。** 每个频段只需要一个 DFT 频点，所以不做整套 FFT，而是用 16 个 Goertzel 滤波器，每个频段一个频点。
   - 每来一个 48 kHz 采样，这 16 个频段**分时复用同一套运算电路**依次计算，每个频段约 7 个时钟。
   - 迭代公式：`s0 = x·w(n) + 2cos(ω)·s1 − s2`，乘法用片上 DSP。
2. **块长随频率变化。**
   - 低频用长块（60 Hz 用 2048 点，约 43 ms），高频用短块（12 kHz 用 32 点）。这样每个频点的宽度约为中心频率的三分之一，和柱子的对数间隔匹配。
   - 各频段的块起点互相错开，保证同一个采样上最多只有一个频段到块尾。
3. **加窗。** 采用 32 级 Hann 窗，减少频谱泄漏。实测单音只会让左右相邻的柱子跟着亮，隔两根以外基本是 0。
4. **求幅度（对数域）。** 块尾得到复数 (re, im)。
   - 用移位归一化求 log2|re| 和 log2|im|，各 3 位小数。
   - 再查一张小表 G 合成 log|X| = max + G(差值)，相当于在对数域里做 √(re²+im²)。
   - 最后换算成像素：高度 = 1.5·L − 该频段的满幅偏置。
5. **存储。**
   - 状态 s1、s2 存在一块 9K 块 RAM 里（32×27 位）。
   - 2cos ω、sin ω 和窗函数存在一块 ROM 里：`display/spectrum_rom.mif`，仿真用 `.hex`。
6. **叠加输出。** 每帧开始时（场消隐期间）统一更新柱高，所以画面不会撕裂。画像素时，在 HDMI 输出前直接改写 RGB。

## 为腾资源做的另一处改动：不再读 EDID

- 频谱运算比原来的柱子大约多 300 个 LUT。只换模块的话，大厅 slice 到 90.80%，超过 90% 后 TD 会跳过保持时间修复。
- 上电时 HDMI 核会读一次显示器的 EDID，但读出的数据（`edid_valid` / `edid_data`）在工程里从来没有用到：我们固定输出 640×480，不需要知道显示器支持什么。
- 所以把 `top_tf_hdmi_audio.v` 里的 `.I_edid_read_trig` 改接 `1'b0`，不再触发读取，TD 随即删掉了这部分逻辑，省出约 300 个 LUT。
- `startup_pulse` 和 DDC 引脚都保留不动，上板行为只是不再去读显示器的 EDID。
- 诊室板不受影响：诊室板是另一个工程，没有改。

## 上板步骤

1. 关掉 TD 再打开大厅工程，确认种子是 5。
2. 确认文件列表里有 `display/audio_bar_visualizer.v`，并且 `display/spectrum_rom.mif` 和它在同一个文件夹（TD 按这个路径找 ROM 初值）。
3. 正常编译，日志里不应出现 "hold fixing is skipped"。只下载到 SRAM。
4. 放音乐，SW2 拨上：柱子应随乐器高低左右跳动，鼓点主要在左边，镲片和齿音主要在右边。
5. 可选：用手机播放"扫频音"，频率从低到高时，最亮的柱子应从左走到右。
