# 陶晶驰触摸屏工程从零制作教程（耳鼻喉科报到登记版）  2026-10-25

本文带你从一个空工程开始，在陶晶驰官方编辑器里做出大厅触摸屏的完整工程，最后下载到屏上和大厅 FPGA 板联调。

- 屏的型号：**TJC8048X270_011R**（7 寸，800×480，电阻触摸）。
- 和 FPGA 的约定：串口 **9600 波特、8N1**，中文用 **GB2312** 编码。
- FPGA 一侧已经做好，不用改。命令的含义见 [TOUCH_CHECKIN_20261025.md](TOUCH_CHECKIN_20261025.md)；本文的代码都已按那份命令表写好，照抄即可。
- 旧工程 `src/tjc_screen/` 是 10 月 16 日的三页版（带 5 张表达卡），只作参考，不要在上面改。

> 本文所有按钮代码都经过检查：`verification/touch_hmi/run_hmi_frames.py` 会直接读本文的代码块，模拟屏发出的字节，送进 FPGA 真实的串口接收和登记代码里，核对登记结果（见第 10 节）。**如果你改了代码块，请重新跑一次这个检查。**

## 1. 做出来是什么样

一共 3 个页面：

│ 耳鼻喉科  门诊报到    │     │ 第1步  沟通需求 [求助]│      │ 第2步  哪里不舒服[求助]│
│ q0：当前006号 下一位… │     │ ┌────────┐┌────────┐ │      │ 主要症状：已选 耳鸣   │
│ ┌──────────┐┌──────┐ │     │ │听力差， ││说话困难│ │      │ [听力下降][耳鸣]…10个 │
│ │          ││请帮助│ │ ──▶ │ │请书写   ││        │ │ ──▶  │ 难受程度：6 级        │
│ │ 开始报到 ││  我  │ │     │ └────────┘└────────┘ │      │ [0][1][2]……[9][10]    │
│ │          │└──────┘ │     │ ┌────────┐┌────────┐ │      │ [上一步][重新填写]    │
│ │          │[重播叫号]│     │ │头晕，   ││需家属或│ │      │        [ 确认报到 ]   │
│ └──────────┘         │     │ │需搀扶   ││手语翻译│ │      │ t0：状态              │
│ t0：报到成功：007号… │     │ [返回][直接报到][下一步]│      │ q0：队列              │
└──────────────────────┘     └──────────────────────┘      └──────────────────────┘
          ▲                                                          │ 确认报到
          └──────────────────────────────────────────────────────────┘
```

患者的操作流程：

1. 主页点“开始报到”。
2. 第 1 步：选沟通需求（可多选，也可以不选），点“下一步”。
3. 第 2 步：选一个主要症状、一个难受程度（都可以不选），点“确认报到”。
4. 回到主页，`t0` 显示“报到成功：007号，前面还有03人”。

另外：

- 每一页都能点“请帮助我”。
- 第 1 步可以点“不填写，直接报到”。

**一个原则：屏只负责“选”和“发”，号码、人数、成功与否全部由 FPGA 回写到 `t0`、`q0` 两个文本框。** 屏上不要自己计数，也不要自己显示“报到成功”。

## 2. 准备

### 软件

- 陶晶驰官方编辑器 **USART HMI**：<http://wiki.tjc1688.com/download/usart_hmi.html>。
  - 我们之前用的是 1.68.1 版。
  - 安装后打开，界面左边是工具箱（控件），中间是画布，右边是页面列表和属性面板，下面是事件代码区。

### 硬件

- 触摸屏本体。
- 屏的 4 针线：+5V、TX、RX、GND。
- 一个 **USB 转 TTL 串口模块**（CH340 / CP2102 都行），用来下载工程到屏。
  - 如果屏背面有 microSD 卡槽，也可以用 SD 卡下载，见第 8 节。
- 5 V 电源：7 寸屏电流比较大，建议用能给 1 A 的 5 V 电源，别只靠 USB 转 TTL 模块的 5 V。

## 3. 新建工程

1. 菜单 **文件 → 新建**，选一个保存位置（路径里最好不要有空格），文件名例如 `ent_checkin`。
2. 弹出“设置”窗口：
   - **设备**：在型号列表里找到 **TJC8048X270_011**（就是 7.0 寸、800×480 的那个型号；末尾的 R 是电阻触摸，列表里不区分）。
   - **显示方向**：横屏 0°。
   - **字符编码**：**gb2312**。这一项必须选对，否则 FPGA 发来的中文会显示成乱码。
3. 点确定，出现一个空白页面 `page0`。

## 4. 做字库

编辑器里所有文字都要用字库。我们做 3 个字库，编号按添加顺序是 0、1、2，后面表格里的“字库”一栏就是这个编号。

| 字库编号 | 字高 | 用在哪 |
|---|---|---|
| 0 | 24 | 小字：提示、症状按钮、t0/q0（第 1、2 步页） |
| 1 | 32 | 中字：标题、需求按钮、主页 t0 |
| 2 | 48 | 大字：主页“开始报到” |

步骤（每个字库做一次）：

1. 菜单 **工具 → 字库制作**。
2. 设置：
   - 字体选“微软雅黑”；
   - 字高填 24（第二次填 32，第三次填 48）；
   - 编码选 **gb2312**；
   - 字符范围选**全部 GB2312 字符**。
   - 不能只选“指定字符”：FPGA 会动态发来各种文字（号码、“2诊室已收到，马上到”等），字库缺字会显示成空白。
3. 字库名称填 `zh24`（`zh32`、`zh48`），点“生成字库”，保存到工程文件夹。
4. 回到主界面，左下角“字库”窗口点 **“+”/添加**，按 24 → 32 → 48 的顺序把三个 `.zi` 加进来。
   - 加完后确认编号：zh24 = 0，zh32 = 1，zh48 = 2。
   - 顺序加错了就删掉重加，否则后面表格里的字库编号对不上。

## 5. 通用规则（每个控件都适用）

### 颜色

属性面板里的颜色可以点色块选，也可以直接填数字。下面是统一用的颜色，数字直接填进属性框：

|---|---|---|
| 页面底色 | 暖白 #FAFAF9 | 65503 |
| 正文 | 深灰 #1F2933 | 6470 |
| 次要文字 | 灰 #6B7280 | 27536 |
| 主色（按钮、强调） | 青绿 #0E6E6E | 2925 |
| 主色按下 | 深青 #0A5050 | 2698 |
| 选中 | 绿 #2E9E5B | 11499 |
| 浅青（症状按钮按下） | #D5ECEA | 55165 |
| 报到按钮 | 琥珀 #F08C00 | 62560 |
| 报到按钮按下 | #C07000 | 50048 |
| 求助 | 红 #D64545 | 53800 |
| 求助按下 | 深红 #A83232 | 43398 |
| 白 | #FFFFFF | 65535 |
| 普通按钮按下 | 浅灰 #C8CDD3 | 52858 |

### 控件属性

- **改名字**：选中控件，在属性面板里改 `objname`。代码里用的名字必须一模一样，大小写也要一样。
- **位置大小**：在属性面板里填 `x`、`y`、`w`、`h`，比拖拽准确。
- **按钮**：
  - `bco` 是平时底色，`bco2` 是按下时的底色；`pco` / `pco2` 是文字颜色。
  - 按下变色是屏自动做的，不用写代码。
- **双态按钮**：
  - `bco0` / `pco0` 是没选中的颜色，`bco1` / `pco1` 是选中的颜色。
  - `val` 是 0 或 1，点一下自动翻转。
- **文本框**：
  - `xcen` 是水平对齐（0 靠左，1 居中），`ycen` 是垂直对齐。
  - `isbr` 是自动换行。
  - `txt_maxl` 是最多能放多少字节（一个汉字 2 字节）。
- **事件代码**：
  - 所有按钮的代码都写在**弹起事件**里，不要写在按下事件。
  - 事件代码区里的“发送键值”勾选框**不要勾**，否则屏会额外发一串触摸数据。FPGA 会忽略这串数据，但没必要。
- **t0、q0 这两个名字不能改，每一页都要有**。FPGA 往当前页的 `t0`、`q0` 写字；某一页没有这两个框，FPGA 的字就显示不出来。
  - `t0`、`q0` 的 `txt_maxl` 一律填 **100**。FPGA 最长的一句约 40 字节，填小了会被截断或报错。
  - `t0`、`q0` 的初始文字留空，FPGA 上电后约 2 秒内会写进来，以后每 2 秒刷新一次。

### 代码规则

1. **每行一条语句**，照抄即可。
2. 屏里的算式没有“先乘除后加减”，所以下面的代码每行只做一次运算，不要合并成一行。
3. `printh` 后面是十六进制字节，用空格隔开，屏会原样从串口发出去。
4. `prints sys0,1` 表示把变量 `sys0` 的值作为 1 个字节发出去。
5. `sys0` 是屏自带的全局变量，换页不会丢。我们用它记住第 1 步选了哪些需求。

### 7.2 事件代码

**页面的前初始化事件**：告诉 FPGA 在登记页，再按 `sys0` 恢复四个按钮的选中状态（从第 2 步点“上一步”回来时，原来的选择还在）：

```tjc page1.preinit
printh 5A 04 01 5F FF FF FF
va0.val=sys0
bt0.val=va0.val%2
va0.val=va0.val/2
bt1.val=va0.val%2
va0.val=va0.val/2
bt2.val=va0.val%2
va0.val=va0.val/2
bt3.val=va0.val%2
```

**bt0~bt3**：不用写代码（点一下变绿，再点一下变白，屏自己处理）。

**b_next 弹起事件**（下一步）：

1. 把四个按钮拼成一个数，存进 `sys0`：听力差 = 1，说话困难 = 2，头晕 = 4，需翻译 = 8，选中的加起来。
2. 发给 FPGA：`5A 05 需求 校验 FF FF FF`。校验 = 95 − 需求。
3. 进第 2 步。

```tjc page1.b_next
sys0=bt3.val
sys0=sys0*2
sys0=sys0+bt2.val
sys0=sys0*2
sys0=sys0+bt1.val
sys0=sys0*2
sys0=sys0+bt0.val
va0.val=95-sys0
printh 5A 05
prints sys0,1
prints va0.val,1
printh FF FF FF
page page2
```

> 为什么校验是 95 − 需求：校验字节 = 5A 异或 05 异或 需求 = 5F 异或 需求。需求只有 0~15，5F 的低 4 位全是 1，异或正好等于 0x5F − 需求 = 95 − 需求。屏里没有异或运算，所以换成减法。

**b_skip 弹起事件**（不填写，直接报到）。先清空，保证真的什么都没登记，再报到，回主页看结果：

```tjc page1.b_skip
printh 5A 08 00 52 FF FF FF
printh 5A 03 00 59 FF FF FF
page page0
```

**b_back 弹起事件**（返回主页）：

```tjc page1.b_back
page page0
```

**b_help 弹起事件**：

```tjc page1.b_help
printh 5A 01 00 5B FF FF FF
```

### 8.3 症状按钮 s0~s9

- s7 的文字里 `\r` 是换行，照原样输入这两个字符，按钮上会显示成两行。

| 按钮 | 按钮文字 | 弹起事件第 1 行 | 弹起事件第 2 行 |

## 9. 编译和在电脑上调试（不用接屏）

1. 点工具栏 **编译**。下方输出窗口应显示 0 个错误。
   - 常见错误：控件名拼错（代码里写的名字找不到）；中文字库没加（提示缺字库）。
2. 点 **调试**，弹出模拟器窗口，可以直接用鼠标点屏。
3. **核对发出的字节**：模拟器右边有“模拟器返回数据”区，每点一个按钮会显示屏发出的十六进制字节。按下面的表逐条核对：

| 操作 | 应该看到的字节 |
|---|---|
| 刚打开（主页） | `5A 04 00 5E FF FF FF` |
| 点“开始报到” | `5A 08 00 52 FF FF FF`，然后 `5A 04 01 5F FF FF FF`（进入第 1 步） |
| 选“听力差”和“需家属或手语翻译”，点“下一步” | `5A 05 09 56 FF FF FF`，然后 `5A 04 01 5F …`、`5A 06 0F 53 …`、`5A 07 0F 52 …` |
| 点“耳鸣” | `5A 06 01 5D FF FF FF`，屏上“未选”变成“耳鸣” |
| 点“6” | `5A 07 06 5B FF FF FF`，屏上显示“6 级” |
| 点“上一步” | 回到第 1 步，听力差和需翻译**仍然是绿色** |
| 点“下一步”，再点“确认报到” | …… `5A 03 00 59 FF FF FF`，然后回主页 `5A 04 00 5E FF FF FF` |
| 点“请帮助我” | `5A 01 00 5B FF FF FF` |
| 什么需求都不选，点“下一步” | `5A 05 00 5F FF FF FF` |

4. **假装自己是 FPGA**：在模拟器下方的“指令输入区”输入下面的命令回车，看字能不能正常显示、有没有被截断：

t0.txt="2诊室已收到，马上到"
```

5. **可选：用电脑直接和 FPGA 联调**。
   - 模拟器的指令输入区可以从“键盘输入”切到“用户MCU输入”，选 USB 转 TTL 的 COM 口，波特率 9600。
   - 把 USB 转 TTL 接到大厅板的触摸屏串口（接法同第 11 节，电脑代替屏）。
   - 这样不下载屏也能先联调。

## 11. 下载到屏

### 方法一：串口下载（一定能用）

1. **先拔掉屏和 FPGA 板之间的线。** 下载时屏的串口只能接电脑。
2. 屏的 4 针接 USB 转 TTL：

| 屏 | USB 转 TTL |
|---|---|
| TX | RX |
| RX | TX |
| GND | GND |
| +5V | 5 V 电源（和 USB 转 TTL 共地） |

3. 编辑器点 **下载**，选 COM 口，波特率选“自动”或 115200，点“联机并开始下载”。
4. 等进度条走完，屏会自动重启，显示主页。

### 方法二：microSD 卡（屏背面有卡槽才行）

1. 编辑器菜单 **文件 → 输出生产文件**，得到一个 `.tft` 文件。
2. microSD 卡格式化成 FAT32，根目录**只放这一个 `.tft`**。
3. 屏断电，插卡，上电。屏会自动升级，显示完成后断电、拔卡、再上电。

## 12. 接到大厅板上联调

### 12.1 接线

屏接大厅板 J1，和以前一样：

| 屏 | 大厅板 |
|---|---|
| TX | J1-39（FPGA 引脚 T15，`tjc_rx`） |

### 12.2 上电后检查

1. 上电约 2 秒内，`q0` 出现“当前---号  下一位---号  候诊00人”。`t0` 出现“请登记后点击“报到””。
   - 不出现就是串口没通：检查 TX/RX 是否接反、是否共地、编辑器里编码是否为 gb2312。
2. 进第 1 步，`t0` 变成“请选择需求后点击“报到””。说明页面通知 `5A 04 01` 收到了。
3. 走一遍登记：选“听力差”、症状“耳鸣”、程度 6，确认报到。主页 `t0` 显示“报到成功：001号，前面还有00人”，`q0` 的人数加 1。
4. 诊室按“叫下一位”：
   - 诊室屏这个诊室那一栏应显示：听力差请书写（红字）、耳鸣、6 级；
   - 听力差的需求卡放大；
   - 大厅屏叫号区黄色闪烁几秒。
5. 点“请帮助我”：
   - `t0` 显示“求助已发出，请稍候”，诊室屏红条闪烁。
   - 诊室确认求助后，`t0` 显示“1诊室已收到，马上到”。
6. 选“直接报到”的患者被叫到时，诊室屏显示“未登记”。

## 13. 常见问题

| 现象 | 原因和办法 |
|---|---|
| FPGA 写来的中文是乱码 | 工程编码不是 gb2312：菜单“设置”里改成 gb2312，重新编译下载 |
| 有的字显示成空白 | 字库没选“全部 GB2312 字符”，重做字库 |
| `t0` 一直空白 | 线没通，或当前页没有名叫 `t0` 的文本框（名字区分大小写） |
| `t0` 的字只显示一半 | `t0` 的 `txt_maxl` 太小，改成 100 |
| 点了按钮 FPGA 没反应 | 代码写在了按下事件里，或者 `printh` 的字节抄错。在模拟器里对照第 9 节的表核对 |
| 登记内容没显示在诊室屏 | 看第 9 节表格里“下一步”是否发出了 `5A 05 …`。另外，从第 1 步点“直接报到”就是不登记 |
| `t0` 被 FPGA 覆盖成别的字 | 正常现象。`t0` 归 FPGA 管，每 2 秒刷新。屏自己的提示请放到 `t_tip`、`t_sym` 这类别的文本框里 |
| 下载失败 | 下载时要拔掉 FPGA 的线；屏供电要足；COM 口选对 |

## 附录：全部命令

`5A cmd arg chk FF FF FF`，chk = 5A ^ cmd ^ arg。

| 用途 | 帧 |
|---|---|
| 页面通知：主页 / 登记页 / 求助页 | `5A 04 00 5E` / `5A 04 01 5F` / `5A 04 02 5C` |
| 清空登记 | `5A 08 00 52` |
| 需求（0~15） | `5A 05 n (95−n)`。例如 0 → `5F`，1 → `5E`，9 → `56`，15 → `50` |
| 症状 0~9 / 未填写 | 见 8.3；未填写 `5A 06 0F 53` |
| 难受程度 0~10 / 未填写 | 见 8.4；未填写 `5A 07 0F 52` |
| 报到 | `5A 03 00 59` |
| 请帮助我 | `5A 01 00 5B` |
| 重播叫号 | `5A 02 00 58` |

表中省略了每帧末尾的 `FF FF FF`。
