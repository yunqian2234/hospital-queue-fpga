## 过渡与时序

大厅页切换/选择/新叫号触发16帧的浅蓝→主题蓝颜色过渡，选中卡/预览面板强调线展开；60Hz下约250ms。工作人员叫号不重启已冻结预览的动画。诊室操作成功提示渐变，未应答求助框32帧往返颜色变化。所有变化在帧边界锁存，不停像素时钟、不阻塞音频、业务或网络。

原照片 fade/wipe、手动切图、自动轮播暂停/10秒恢复和缩略图功能保持。显示缩略图定位至(160,64)，但 SDRAM 读取仍使用原逻辑缩略图坐标(0,0)；两者不得混淆。波形保留采样快照/峰值，以14列、每列8像素显示，避免常数除7硬件开销。

保留10/14青屏修复：官方 HDMI 核直接接连续固定光栅，不重新接弹性 FIFO；TLAST=638不变。诊室生产顶层的屏幕坐标改为 video_y-45，与640×480有效区一致。无新时序例外、PLL相位或网口 DDR 改动。
